# 电智学伴主人的 AI 成长路线 V4.0（帕累托最优版）

> 生成日期：2026-09-05 · 基于 Kimi 建议稿经 4 轮正反专家组对抗审查收敛
> 适配对象：大二电气自动化 · 考研复试备战中 · 零代码基础 · 已有 OpenClaw/电智学伴实操 · 有大赛杠杆
> 配套：本文件存放于项目 git 仓库中（commit 511bbc1 之后），可随项目一起版本管理

## 一、三大铁律

1. **考研第一**：任何 AI 学习不得挤占考研复习主线；冲突时 AI 学习让路。
2. **验证优先，默认怀疑**：AI 给的代码默认有 bug；判断对错靠"跑起来看结果是否符合预期"，不靠 AI 自圆其说。
3. **先提交再动手**：每次让 AI 改代码前，先 `git commit` 存档（改坏一键回滚）。

## 二、双轨时间预算（弹性制）

| 学期状态 | AI 学习时间 | 构成 |
|---|---|---|
| 考试周/考研冲刺 | 2h/周（保底不断档） | 1 个概念视频 + 让 AI 解释 1 段自己项目的代码 |
| 平时 | 5-8h/周 | 3h 代码 + 2h 折腾电智学伴 + 1h 概念 + 1h 输出 |
| 寒暑假 | 12-15h/周 | 竞赛备赛 + 系统补课 |

## 三、代码能力轨道（12 个月，验收驱动）

| 阶段 | 目标 | 验收标准 |
|---|---|---|
| M0（第 1-2 周） | 认识项目骨架 + git 保命 | 能画出"请求怎么走"流程图；能回滚 |
| M1（第 1-2 月） | 函数级阅读 | 能指着 main.py 任一函数说出输入/输出/作用 |
| M2（第 3-4 月） | 亲手小改 | 独立完成一个前端小功能并部署 |
| M3（第 5-8 月） | 独立排错 | 独立定位并修复一个后端 bug |
| M4（9-12 月） | 系统化 | 能给电智学伴设计新功能并说清架构 |

**验证三问**（每次 AI 交付代码后必问）：① 能启动吗？② 测试输入输出符合预期吗？③ 边界情况（空输入/断网/超长）会怎样？

## 四、AI 原理轨道

| 层级 | 内容 | 载体 |
|---|---|---|
| L1 应用层 | Prompt、RAG、Agent 概念 | 吃透 OpenClaw（tools/session/automation/记忆） |
| L2 开发层 | 调 API、向量检索、评估意识 | 给电智学伴加"答案自评/引用准确率统计" |
| L3 原理层 | 概念直觉即可 | 吴恩达前几章 + 科普视频；微调/Transformer 只了解能讲 |

**明确砍掉**：LangChain/LangGraph 系统学习（用 OpenClaw 替代）、模型微调实操。

## 五、作品与竞赛轨道（一鱼四吃）

1. 按大赛节点倒排：deadline = 学习 deadline
2. 迭代：Phase1 聊天 → Phase2 RAG（已完成）→ Phase3 电路图识别/错题本/公式推导（一次加一个功能）
3. 开源记录：GitHub + 每次 AI 改代码的对话存 docs/
4. 反馈回路：给考研同学用 → 反馈 = 判断对错的最真实依据
5. 作品叙事：电智学伴 → 自动化小脚本 → 垂直 RAG demo

## 六、副业闸门（大三后再启动）

1. 先免费后收费，冷启动 = 校园/考研社群口碑
2. 安全红线：真实设备/电力系统输出一律标注"仅供学习，工程需复核"
3. 可做方向（门槛排序）：考研题库 AI 化 → 课程笔记知识库 → 设备手册问答 demo
4. **划掉**：AI 生成 PLC 代码类副业（安全隐患）

## 七、30 天启动包

| 天 | 动作 | 验收 |
|---|---|---|
| D1 | 装 Git + 项目 git init + 首次 commit | `git log` 有记录 ✅ 2026-09-05 完成（commit 511bbc1）|
| D2 | 让 AI 画出 main.py 结构图并讲解 | 能复述请求流程 |
| D3 | 学 if/else/for/函数概念 | 能看懂 60% 控制流 |
| D4 | AI 逐行讲解 retriever.py 的 retrieve | 能说出输入→输出 |
| D5 | 练 git commit + 回滚 | 能自己回滚一次 |
| D6 | AI 辅助加最简前端功能 | 功能上线 |
| D7 | 200 字周记（3 个"原来如此"） | 笔记完成 |

每周循环：1 概念 + 1 次项目小改 + 1 篇输出。

## 残留异议（反方专家组保留）

1. "验证三问"对大二生偏抽象 → 用"给同学用、看反馈"补足
2. 砍微调/LangChain 可能面试露怯 → L3 保留概念，按需加深
3. 12 个月可能被考研打断 → 弹性制保底 2h/周，断档不致命
